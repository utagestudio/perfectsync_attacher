# 紹介動画

正式版1.0.0で、D&D待機画面にサムネイル付き「使い方を見る」ボタンを追加。ユーザー提供の告知動画を音声付きで再生します。

- クリックでモーダルを開き、再生を開始。ブラウザーが開始を拒否した場合は再生ボタンの案内を表示します。
- 動画のsrcはクリック時に設定し、初期表示では動画本体を取得しません。
- 標準の動画コントロールで再生・停止・音量・ミュート・全画面表示が可能。端末によって操作の見え方は異なります。
- 閉じるボタン、Esc、背景クリックで閉じ、再生を停止してsrcを解除します。フォーカスは開始ボタンへ戻ります。
- タブが非表示になった場合やページを離れた場合にも停止します。
- ボタン・説明は5言語に対応。動画内の画面が日本語であることと、約1分・音声ありを案内します。
- 動画の再生イベントはアクセス解析へ送信しません。

## 配信素材

`public/media/introduction.mp4`は約58秒、1280×720、H.264/AAC、約3.6MB。元動画からWeb用に圧縮し、音声と画面内クレジットを維持しています。サムネイルは`introduction-poster.jpg`。いずれも同一サイトから配信し、外部動画プレーヤーは使用しません。

動画は利用者提供の紹介素材で、本体コードのMITとは別に扱います。BGMの出所は動画内のBGMer表記です。素材の利用・再配布条件は本体のMITによる許諾に含めません。

## 検証

Chromeで初期表示時の動画未取得、クリック後の音声付き再生、閉じる・Esc・再表示、5言語と小画面の配置、通常のVRM変換を検証します。Safari／Firefoxの実機確認は未実施です。
