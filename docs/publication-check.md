## Git・配信物

- 作業開始時の全14コミット・86個の異なるblobを、秘密鍵・AWSアクセスキー・GitHubトークン・長い認証値の代入等のパターンで確認し、今回の変更差分も確認した。パターン検査とコード確認であり、未知の秘密情報を完全に検出する保証ではない。
- `_local/`、node_modules、dist、環境ファイル、秘密鍵、復元用bundle等の追跡はなかった。私有VRM本体と画像も履歴に含まれない。テンプレートGLBは公開元由来の加工データとして区別する。
- 検証モデルのファイル名は過去の文書・テストに記載されている。モデル本体の公開ではないが、名前を非公開にしたい場合は履歴を含めた匿名化が別途必要。本チェックでは追加の履歴書き換えはしていない。
- 現在の著者・コミッターは`utagestudio`で統一。旧名義のバックアップはignoreされた`_local/git-backups/`だけに置いている。
- `.gitignore`に`.env`系列と秘密鍵等を追加。開発・プレビューサーバーは127.0.0.1に限定し、開発サーバーはローカルモデル・Git内部・環境ファイル・鍵の配信を拒否する。
- distはHTML、JS、CSS、ヘッダー設定、ライセンス、テンプレートと出所情報のみ。私有VRM、ローカル絶対パス、旧名義、source mapを含まない。public内のsymlinkもない。
- `gh repo view`でリモートがPUBLIC、既定ブランチ参照が空であることを確認した。本チェックではリモートを変更していない。

## 入力・実行・通信

- GLBのヘッダー、chunk境界、bufferView、全accessorの数・参照範囲・整数値・sparse参照を確認する。顔の属性型、頂点・indices数、primitive数、変換後BINの推定容量も制限する。詳細は[プロトタイプ確認ガイド](prototype-guide.md)を参照。
- 変換はWeb Worker内で実行し、ブラウザー側で120秒の上限を設ける。キャンセル・失敗後はファイルを選び直せる。
- 外部バッファ・画像を拒否する。プレビューローダーも埋め込み画像用blob以外の参照を拒否し、同一オリジンの任意URLへの参照も許可しない。
- ファイル名・エラー・表情名等はtextContentで表示し、モデル由来文字列をHTMLとして挿入しない。不正ファイル名によるHTML挿入をブラウザーで検証した。
- 現在のコードにはモデルアップロード・アクセス解析・外部API呼び出しがない。変換・保存・プレビュー中の通信は同一オリジンのGETとblob内に限定され、POST等は発生しなかった。
- 配信用CSPはself中心、object・base・frame・formを禁止。nosniffとno-referrerも設定する。Cloudflare Pagesの`_headers`設定は確認済みだが、実際の配信レスポンスへの適用はデプロイ後に確認する。
- ファイルサイズ等の上限はブラウザーの総メモリー使用量を保証しない。埋め込み画像の展開やGPU資源、低メモリー端末での負荷・WebGLドライバーの挙動は今回の検証範囲外。
