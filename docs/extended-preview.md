# プレビューの限界突破モード

開発版 `0.3.0-dev.9` で追加。各表情の「限界突破」をONにすると、スライダーの範囲を通常の0〜100%から−100〜200%へ変更します。初期状態はOFFです。スライダー右側の小さなボタンで切り替え、ON時は緑色で表示します。キーボードのEnter・Spaceでも操作できます。

- ONへの切替では現在値を保持します。
- OFFへの切替では現在値を0〜100%の範囲に収めます。
- 「すべてリセット」は全項目を0%、限界突破をOFFに戻します。
- 言語切替では値とON/OFFを保持します。別のファイルの読み込みでは初期化します。
- プレビューのみの機能です。変換済みVRMのダウンロード内容には反映しません。外部のトラッキングアプリで範囲外の値が動作することは保証しません。

範囲外では顔が崩れたり、口内が突き抜けたりする場合があります。注意文は操作説明の下に固定表示し、スライダーのみをスクロールします。ユーザー指定の範囲を新しい0〜100%として出力へ焼き込む編集機能は、今回の対象外です。

## 実装

three-vrmの通常のexpressionManagerは値を0〜1へ制限します。通常のVRM更新の後で、要求値と制限された値の差分をMorph Target Bindへ追加します。次の更新ではライブラリがMorph Targetをクリアするため、差分は累積しません。材質・テクスチャのBindには範囲外の差分を適用しません。ライブラリの改変は不要です。

## 検証

実際のthree-vrmを使った単体テストで、負の値、100%超、同じMorph Targetへの複数表情、連続更新、通常範囲への復帰を検証します。ChromeのブラウザテストでON/OFF、リセット、言語切替、ダウンロードURL保持、小画面のページ全体スクロールなしを確認します。

## ボタンのフォント

Google FontsのDela Gothic Oneを日本語・英語のボタン文字に適用。必要な文字のみのサブセットを`public/fonts/`に同梱し、自サイトから配信します。その他の言語の未収録文字はシステムフォントへフォールバックします。出所とライセンスは同ディレクトリに保存しています。
